# Library Management System

## Aim

To develop a simple Library Management System and implement
an automated CI/CD pipeline using GitHub Actions.

## Description

The Library Management System is a web application that allows
users to manage library books.

## Features

- Add new books
- View available books
- Search books
- Delete books
- Display book details

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Actions

## Project Structure

LibraryManagementSystem/

- index.html
- style.css
- script.js
- README.md

## CI/CD Pipeline

The project uses GitHub Actions to automatically perform:

1. Build
2. Test
3. Package
4. Deploy

## Deployment

The application is deployed using GitHub Pages.

## Result

The Library Management System was successfully integrated
with a CI/CD pipeline using GitHub Actions.
